# 十阶段开发计划

每阶段都按检查、最小实施、真实编译、运行、记录和验收执行。阶段 1 的最终状态见 Phase1Acceptance.md。阶段 2 已完成 2.1—2.5，并通过真实编译和完整 PIE 回归，范围、首轮失败及限制见 [Phase2_5Acceptance.md](Phase2_5Acceptance.md)。阶段 3—10 仍为计划，尚未开始。

| 阶段 | 范围 | 必须满足的验收标准 |
| --- | --- | --- |
| 1 工程初始化 | 官方第三人称 C++ 基线、环境、文档、Git/LFS | UHT/MSVC/链接真实成功；编辑器加载正确地图；实际移动、视角、跳跃、停止；LFS 实际索引/对象核验；未批准不提交。 |
| 2 角色控制 | 本地输入、移动、相机、状态边界 | 键鼠操作、输入切换、边界/碰撞、帧率差异测试通过；实际编译和 PIE；不混入战斗开发。 |
| 3 战斗基础 | 单一动作链、命中、受击、死亡 | 可重复命中测试、重复事件防护、动画与规则一致；离线运行无关键错误。 |
| 4 属性与技能 | 最小属性集、技能资源与冷却 | 边界值、成本不足、冷却与存档一致性有测试。 |
| 5 怪物 AI | 一类敌人的感知、追击、攻击、恢复 | 导航、不可达目标、失去目标、死亡清理可重复验证。 |
| 6 地图与探索 | 小型区域、交互、场景组织 | 出生/切换/碰撞正确；目标硬件性能预算有实测数据。 |
| 7 背包与装备 | 物品实例、容器、装备效果 | 添加/移除/满包/重复操作正确；UI 与数据一致。 |
| 8 任务流程 | 一条完整本地任务链 | 接取、推进、完成、中断恢复及异常顺序测试通过。 |
| 9 存档与完整 UI | 本地 SaveGame、版本和菜单 | 首次启动、读写、损坏存档、版本迁移、重启恢复通过。 |
| 10 集成与发布基线 | Windows 打包、性能、回归 | 打包真实成功；脱离编辑器离线启动；主流程回归；发布记录、已知问题和可复现构建齐全。 |

每个阶段必须冻结明确验收范围，失败先定位，不能用后续功能掩盖当前缺陷。资源和插件依赖变更需评估体积、许可与离线可用性。
